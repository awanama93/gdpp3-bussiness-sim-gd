Player character bisa membawa [[TetrominoPackage|tetromino package]]
Membawa package berarti menempatkan package di tangan
Pada satu waktu player character hanya bisa membawa satu package
Tetapi player character bisa [[MenukarPackage|menukar]] package yang sedang dibawa dengan package yang sedang [[MemikulPackage|dipikul]]

Setelah melakukan [[MembukaAbility|pembukaan ability]] player character bisa melihat informasi daftar [[Part|part]] dari package yang sedang dibawa pada user interface
