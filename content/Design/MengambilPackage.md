Player character bisa mengambil [[TetrominoPackage|tetromino package]] yang sudah disimpan di game space

Player character bisa mengambil package hanya jika ketika package itu diambil, total beban yang dia bawa tidak melebihi [[CarryCapacity|carry capacity]] ^hold-requirement

Jika player character mengambil package, maka package tersebut akan menjadi package [[MembawaPackage|yang dibawa]] player character
Lalu, package yang sebelumnya dibawa player character dipindahkan ke tumpukan paling atas package yang sedang dipikul
