Player character bisa menyimpan [[TetrominoPackage|tetromino package]]
Player character bisa menyimpan package langsung di lantai atau di atas package lain
Ketika akan menyimpan package, player bisa melihat [[PackagePlacementPreview|bayangan preview lokasi]] package disimpan. Jadi player bisa memperkirakan apakah dia akan menaruh package tersebut atau tidak

Jadi urutannya adalah:
Player memilih package yang ingin dia simpan
Player masuk ke tahap [[PackagePlacementPreview|bayangan preview lokasi]]
Player memutuskan lokasi penyimpanan package
Player menyimpan package
