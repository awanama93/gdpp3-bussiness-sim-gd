Player character bisa menumpuk [[TetrominoPackage|tetromino package]] di mana pun di lantai game space
Pada saat akan menumpuk package, player bisa melihat [[PackagePlacementPreview|bayangan preview lokasi]] package ketika disimpan pada tumpukan
Posisi penumpukan tidak snapping ke package di bawahnya, melainkan langsung ditaruh di mana pun dia ditempatkan
Ini berarti package bisa ditaruh tidak simetris dengan package yang ada di bawahnya
Karena package memiliki [[PackagePhysic|package physic]] maka ketika ditumpuk dengan tidak ditopang dengan baik, package bisa jatuh
Maksimal player character bisa menumpuk 6 package
