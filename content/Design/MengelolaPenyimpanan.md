Player character bisa melakukan pengelolaan penyimpanan [[TetrominoPackage|tetromino package]]
Pengelolaan di sini berarti player character bisa membuat keputusan tentang:
Di mana akan menaruh suatu package
Di mana akan menumpuk suatu package

Jadi player diberikan kebebasan untuk melakukan semua itu
Keputusan ini berdampak pada seberapa mudah game space dinavigasi dan seberapa mudah package [[MenemukanPackage|ditemukan]]
